# Katalog Produk Ami

Aplikasi katalog produk berbasis **JavaFX** yang digunakan untuk mengelola data produk dengan database SQLite.

## Fitur
- Menambahkan produk
- Menampilkan daftar produk
- Mengubah data produk (Update)
- Menghapus produk (Delete)
- Menampilkan gambar produk

## Teknologi
- Java 17
- JavaFX 21
- SQLite
- Maven

## Tampilan Produk
Aplikasi menampilkan katalog produk seperti susu, roti, dan kopi.

## Cara Menjalankan
1. Clone repository ini.
2. Buka project menggunakan NetBeans.
3. Pastikan Maven sudah terpasang.
4. Jalankan aplikasi melalui perintah:

```bash
mvn clean javafx:run
```
